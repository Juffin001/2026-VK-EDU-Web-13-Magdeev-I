В задании было сказано про разные состояния для авторизованных/неавторизованных пользователей, поэтому я добавил немного кода на js, чтобы при нажатии на войти или зарегистрироваться пользователь входил в аккаунт (который правда пока один по умолчанию), аналогично с кнопкой выхода из аккаунта. Страница профиля является страницой настройкой профиля, поэтому место profile.html занимает settings.html (изначально я ориентировался на рисунки макетов, где эта страница и называется settings.html).
